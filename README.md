# Basic Calculator 🧮

A simple and user-friendly Basic Calculator built using HTML, CSS, and JavaScript. It performs basic mathematical operations with a clean and responsive user interface.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)


## 🛠️ Technologies Used

- HTML5 – Structure of the calculator
- CSS3 – Styling and layout
- JavaScript – Calculator logic and functionality

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start performing calculations!

## 📂 Project Structure

```text
Basic-Calculator/
├── index.html
├── style.css
├── script.js

```

The objective of this project is to practice HTML, CSS, and JavaScript fundamentals while building a functional calculator.
